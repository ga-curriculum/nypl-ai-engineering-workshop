# Capstone Challenge

## Overview

| Detail | Info |
|---|---|
| **Duration** | 45 minutes |
| **Position** | 3:00–3:45 PM |
| **Tools** | Google Gemini + GitHub Copilot |
| **QA Personas** | All — participant's choice |

## The Challenge

A timed feature sprint that brings together everything from the workshop:
- Dual-tool workflow (Gemini + Copilot)
- Task decomposition
- AI-assisted testing
- QA Refinement Framework (Generate > Review > Refine)

## Challenge Brief

*To be developed — will include a feature spec for the sandbox codebase that requires participants to:*

1. **Decompose** the feature using Gemini (5 min)
2. **Implement** using Copilot with Gemini guidance (20 min)
3. **Test** using AI-generated tests, reviewed with a persona (10 min)
4. **Review** using at least 2 QA personas of their choice (10 min)

## Evaluation Rubric

See [rubric.md](rubric.md) for detailed scoring criteria.

## Tiered Expectations

| Tier | Minimum Deliverable |
|---|---|
| Base | Working feature + 3 tests + 1 persona review |
| Intermediate | Working feature + 5 tests + 2 persona reviews + edge case handling |
| Stretch | Working feature + comprehensive test suite + all personas + written reflection |
