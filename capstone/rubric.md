# Capstone Evaluation Rubric

## Scoring Categories

### 1. Task Decomposition (20 points)

| Score | Criteria |
|---|---|
| 20 | Feature broken into clear, logical steps; each step is AI-appropriate in scope |
| 15 | Reasonable decomposition with minor gaps in step sizing |
| 10 | Decomposition attempted but steps are too large or too vague |
| 5 | Minimal decomposition; jumped straight to implementation |

### 2. Implementation Quality (30 points)

| Score | Criteria |
|---|---|
| 30 | Feature works correctly; code is clean, well-named, handles errors |
| 22 | Feature works; minor readability or error-handling gaps |
| 15 | Feature partially works; some issues with logic or structure |
| 8 | Feature attempted but doesn't work or has significant issues |

### 3. AI Tool Usage (20 points)

| Score | Criteria |
|---|---|
| 20 | Effective use of both Gemini Code Assist and Copilot; each tool used for its strengths |
| 15 | Good use of tools but leaned heavily on one; missed opportunities for the other |
| 10 | Used tools but without clear strategy; prompts were vague |
| 5 | Minimal tool usage; mostly manual coding |

### 4. Testing (15 points)

| Score | Criteria |
|---|---|
| 15 | Tests cover happy path + edge cases; no hallucinated assertions; tests are specific |
| 11 | Tests cover happy path; some edge cases; minor assertion issues |
| 7 | Tests present but shallow; missing edge cases or contain hallucinated assertions |
| 3 | Minimal or no tests |

### 5. QA Review (15 points)

| Score | Criteria |
|---|---|
| 15 | Applied 2+ personas; identified real issues; refined code based on findings |
| 11 | Applied 1 persona thoroughly; some refinement based on findings |
| 7 | Review attempted but superficial; no meaningful refinement |
| 3 | No review step applied |

## Total: 100 points

| Grade | Score | Description |
|---|---|---|
| Exceeds Expectations | 85–100 | Ready to integrate AI tools into daily workflow |
| Meets Expectations | 65–84 | Solid foundation; needs practice to build fluency |
| Approaching | 45–64 | Understands concepts; needs more hands-on time |
| Needs Support | Below 45 | Requires additional training or 1:1 guidance |
