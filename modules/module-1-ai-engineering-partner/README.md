# Module 1: AI as an Engineering Partner

## Overview

| Detail | Info |
|---|---|
| **Duration** | 90 minutes (60 min lecture + 30 min Lab 1) |
| **Position** | 9:15–10:45 AM |
| **Tools** | Google Gemini + GitHub Copilot |
| **Lab** | Lab 1: Gemini Reasoning |

## Learning Objectives

By the end of this module, participants will be able to:
1. Explain the strengths of Gemini (reasoning, planning) vs. Copilot (inline completion, context-aware suggestions)
2. Write effective prompts for both tools using the context-specificity framework
3. Use the dual-tool workflow: Gemini for thinking, Copilot for building
4. Apply the Generate > Review > Refine loop to their first code generation task

## Content Outline

### Part 1: The Dual-Tool Framework (20 min)
- Why two tools? Complementary strengths, not competing products
- Gemini: best for reasoning, multi-step planning, code review, explanation
- Copilot: best for inline completion, code generation in-editor, chat-based coding
- Demo: Same task approached with each tool — different strengths visible

### Part 2: Effective Prompting for Code (25 min)
- The context-specificity spectrum: vague prompt vs. high-context prompt
- Prompt patterns: role-based, constraint-based, example-driven
- Live exercise: Participants rewrite a vague prompt into a high-context prompt
- Peer review: Round-robin prompt evaluation

### Part 3: Lab 1 — Gemini Reasoning (30 min)
- Hands-on exercise using Gemini for code analysis and planning
- See [labs/lab-1-gemini-reasoning/](../../labs/lab-1-gemini-reasoning/)

### Part 4: Debrief (15 min)
- Share findings from Lab 1
- Introduce the QA Refinement Framework (Generate > Review > Refine)
- Preview: Pre-commit review template
