# Lab 4 Review Checklist — Security Auditor

After labeling the code samples, apply this security review to the ones you identified as AI-generated.

## Persona: Security Auditor

Use this prompt with Gemini:

```
Act as a senior security auditor. Review the following Python code
that was generated by an AI tool and is about to be committed to
a production repository.

Check for:
1. Input validation gaps
2. Injection vulnerabilities
3. Authentication/authorization issues
4. Sensitive data exposure
5. Error handling that leaks internal details
6. Unsafe patterns that AI commonly introduces

For each finding:
| Issue | Severity (Critical/High/Medium/Low) | Location | Recommended Fix |

[paste the AI-generated code sample here]
```

## Checklist

For each AI-generated sample, verify:

- [ ] No hardcoded secrets or credentials
- [ ] Input validation is sufficient for production use
- [ ] Error messages don't expose internal details
- [ ] Financial calculations use appropriate precision (Decimal, not float)
- [ ] State transitions are fully validated
- [ ] No unusual import patterns or anti-patterns
- [ ] Edge cases are handled (empty input, None values, negative numbers)
- [ ] The code doesn't blindly trust input data types

## Key Question

For each AI-generated sample, ask yourself:

**"If this code caused a production incident, would I be comfortable explaining to my team that I reviewed it before committing?"**

If the answer is no, the code needs more review before it ships.
