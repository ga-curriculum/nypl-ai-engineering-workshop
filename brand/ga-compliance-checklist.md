# GA Brand Compliance Checklist

Verify all materials meet General Assembly brand requirements before delivery.

## Content Requirements

- [ ] All slide decks use GA-approved templates
- [ ] GA logo appears on first and last slides
- [ ] Copyright notice: "General Assembly — All rights reserved"
- [ ] No competitor logos or branding in materials
- [ ] Client name (NYPL) used correctly and consistently
- [ ] Workshop title matches contract: "AI-Assisted Software Engineering"

## Tool References

- [ ] Only Google Gemini and GitHub Copilot are referenced as participant tools
- [ ] No references to GPT, OpenAI, ChatGPT, or LangChain in participant-facing materials
- [ ] Tool names are capitalized correctly (Google Gemini, GitHub Copilot)
- [ ] No endorsement language — tools are presented as options, not recommendations

## Accessibility

- [ ] All images have alt text
- [ ] Slide text meets minimum contrast requirements
- [ ] Code samples use a readable font size (14pt+)
- [ ] Color is not the only way information is conveyed

## Legal

- [ ] Workshop materials are marked as GA intellectual property
- [ ] Participant materials include appropriate usage rights
- [ ] No third-party copyrighted code in exercises without attribution
- [ ] API keys and credentials are not included in distributed materials

## Delivery Materials Checklist

- [ ] Facilitator guide — final version reviewed
- [ ] Participant handout — printed or digital distribution ready
- [ ] Slide decks — all 4 modules
- [ ] Lab materials — all 4 labs with starter, solution, and review folders
- [ ] Capstone — challenge brief, rubric, starter code
- [ ] Environment setup — tested on clean machine within 1 week of delivery
